## Brand & Style

This design system delivers a high-conviction fintech and venture intelligence platform designed for institutional angel syndicates, venture capitalists, and data-driven investment committees. The emotional tone is decisive, surgical, analytical, and authoritative—bridging the cold precision of high-frequency trading terminals with the refined polish of tier-one venture capital dossiers.

The design movement combines **Terminal-Inspired Technical Minimalism** with **Refined Dark Glassmorphism**. Heavy, deep obsidian surfaces anchor dense information architecture without visual noise. Laser-sharp borders, translucent micro-surfaces, and glowing real-time telemetry elements establish a feeling of real-time computational power and unyielding intellectual rigor. The interface rejects consumer-grade softness in favor of dense data clarity, razor-sharp status indicators, and confident typographic hierarchies that treat investment intelligence as mission-critical instrumentation.

## Colors

The palette operates in a default dark execution, utilizing a structured spectrum of deep space obsidian and slate tones to provide maximum contrast for streaming telemetry and analytical metrics.

- **Primary (`#00F0FF`)**: Electric Cyan signifies active computation, live streaming WebSocket events, LangGraph node execution states, and telemetry data beacons.
- **Secondary (`#10B981`)**: Institutional Emerald represents validated consensus, grounded RAG citations, high conviction scores (7.5–10.0), and affirmative agent reconciliation.
- **Tertiary (`#6366F1`)**: Deep Indigo provides architectural anchoring for structural categories, syntactic tagging, and synthesis processing nodes.
- **Neutral (`#94A3B8`)**: High-legibility slate gray engineered for reading dense investment memos, secondary metadata, and structural micro-copy across high-density layouts.

### Status & Confidence Tiers
- **Conviction / High (`#10B981`)**: Strong conviction, grounded RAG verification, low variance.
- **Contested / Medium (`#F59E0B`)**: Agent debate detected, fallback Tavily queries engaged, partial verification.
- **Low / Risk (`#F43F5E`)**: Hallucination tripwire triggered, negative synthesis score, groundedness check failed (`confidence: "low"`).

## Typography

The typographic system utilizes a purposeful three-tier font hierarchy:

1. **Display & Section Headers (`Space Grotesk`)**: Provides geometric precision, forward-looking architectural poise, and modern technical punch. Headlines must maintain tight negative letter-spacing for an institutional editorial feel.
2. **Body Prose & Analytical Memorandums (`Inter`)**: Delivers supreme optical clarity, neutral reading comfort, and balanced tall x-height for evaluating dense startup analyses, contradiction matrices, and market breakdowns.
3. **Telemetry, Data & Agent Shell Logs (`JetBrains Mono`)**: Handles all live execution steps (`agent:step`), vector chunk IDs (`chunk_0193`), API latency indicators, and 0–10 conviction scoring metrics. Every metric and code readout is strictly monospaced to prevent optical jitter as values stream over WebSockets.

## Layout & Spacing

The layout is built on a 12-column fluid responsive grid bounded by a max container width of `84rem` (1344px) for data dossiers and terminal interfaces.

- **Desktop (1024px+)**: 12 columns, 24px (`1.5rem`) gutters, and dynamic margins. Displays parallel research node cards in 4-column subgrids (Market, Competitor, Financial, Risk) feeding downward into the Synthesizer reconciliation engine.
- **Tablet (768px - 1023px)**: 8 columns, 16px (`1rem`) gutters. Research agents stack into a 2x2 modular matrix.
- **Mobile (<768px)**: 4 columns, 16px (`1rem`) gutters and horizontal margins. Agent streams collapse into tabbed horizontal panes or vertical accordion threads to preserve log readability without horizontal scroll.

Spacing rhythm follows a rigorous 4px/8px base factor. Information density is prioritized: data containers utilize compact vertical padding (`0.75rem` to `1rem`) paired with ample structural negative space between major workflow zones (`2rem` to `3rem`).

## Elevation & Depth

Visual hierarchy operates via **Tonal Layering and Glassmorphic Micro-Borders** rather than heavy drop shadows:

- **Base Layer (`#0A0D14`)**: The canvas floor. Pure dark obsidian representing the backend environment.
- **Level 1 Panels (`#101622`)**: Agent activity cards, main intake surfaces, and dossier modules. Outlined with a continuous `1px` subtle boundary (`#223147`).
- **Level 2 Flyouts & Terminals (`#172133`)**: High-priority inspection panels, raw JSON inspectors, and live execution sub-terminals. Backdrops utilize `backdrop-filter: blur(12px)` with an ultra-fine border highlight on the top edge (`rgba(255, 255, 255, 0.08)`).
- **Interactive & Real-Time Focus**: Active streaming cards receive an external glow shadow: `0 0 20px -4px rgba(0, 240, 255, 0.15)` paired with a cyan border highlight (`#00F0FF66`).
- **Alert & Contradiction Nodes**: Low-confidence or flagged agent findings deploy an ambient rose warning tint: `0 0 24px -6px rgba(244, 63, 94, 0.12)`.

## Shapes

The design system maintains a **Soft-Structured (Level 1)** geometry with `0.25rem` (4px) to `0.5rem` (8px) corner radii. This maintains the crisp, non-frivolous silhouette of an institutional trading floor or Bloomberg terminal, softened just enough to convey modern developer-grade sophistication.

- Standard buttons, input fields, and telemetry badges use `rounded` (`0.25rem` / 4px).
- Research agent cards, dossier containers, and data charts use `rounded-md` (`0.375rem` / 6px) to `rounded-lg` (`0.5rem` / 8px).
- Status pulse pips and conviction score gauges remain strict circles (`rounded-full`), balancing the geometric linearity of the grid.

## Components

### Buttons & Interactive Triggers
- **Primary Execution (Action)**: Background `#00F0FF`, text `#0A0D14`, font `JetBrains Mono` 13px bold uppercase. Subtle cyan glow on hover (`box-shadow: 0 0 16px rgba(0, 240, 255, 0.4)`).
- **Secondary (Inspect / Action Secondary)**: Background `#172133`, border `1px solid #223147`, text `#E2E8F0`. Hover triggers border transition to `#00F0FF80`.
- **Destructive / Flag**: Background transparent, border `1px solid #F43F5E40`, text `#F43F5E`. Hover fills with `rgba(244, 63, 94, 0.1)`.

### Live Telemetry Agent Cards
- Multi-state containers reflecting LangGraph orchestrator steps (`idle`, `planning`, `retrieving`, `fallback`, `reasoning`, `done`).
- Header includes agent title, model tag (`LLaMA 3.3-70B`), and a streaming status pill with a pulsing beacon dot (Cyan for active, Emerald for done, Rose for low-confidence fallback).
- Inner body houses a live terminal stream displaying sub-questions and chunk citations in monospaced format (`#64748B` default, active steps highlight to `#00F0FF`).

### Conviction Gauge & Metric Displays
- Verdict Score is presented in a large terminal block (`32px` JetBrains Mono) with a 0.0 to 10.0 numeric rating.
- Color shifts dynamically based on range:
  - **8.0 - 10.0**: Emerald (`#10B981`) with label "HIGH CONVICTION".
  - **5.0 - 7.9**: Amber (`#F59E0B`) with label "CONDITIONAL / CONTESTED".
  - **0.0 - 4.9**: Rose (`#F43F5E`) with label "HIGH RISK / PASS".

### Input Fields & Search Bars
- Background `#101622`, border `1px solid #223147`, text `#E2E8F0`, placeholder `#64748B`.
- Focus state: Border transitions to `#00F0FF`, inset micro-glow `0 0 0 1px #00F0FF40`.
- Integrated monospace command cues (`[Enter ↵]` or `[Ctrl+K]`) pinned to the right edge in `#64748B`.

### Citations & Chunk Badges
- Interactive micro-tokens representing embedded chunks (e.g., `[chunk_0193]`).
- Styled with `background: #172133`, border `1px solid #223147`, text `#00F0FF`, font `JetBrains Mono` 10px. Hover reveals the grounded PDF source snippet in an elevated glassmorphic tooltip.

### Debate & Contradiction Cards
- Two-column reconciliation row highlighting points of synthesis between agents.
- **Agreement**: Border-left `3px solid #10B981`, surface tint `rgba(16, 185, 129, 0.03)`.
- **Contradiction**: Border-left `3px solid #F43F5E`, surface tint `rgba(244, 63, 94, 0.03)`, showing competing agent badges and unresolved discrepancies.
